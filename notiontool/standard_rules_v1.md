# Standard rules v1

These rules apply to every development task unless the task says otherwise.

1. Write only the files listed in the task. Never create, edit or delete any other file.
2. Use LF line endings and no BOM unless the task says otherwise.
3. No git push, no restart of NotionTool and no live Notion calls.
4. Before you edit an existing file, make a backup copy of it.
5. Prove your work: for every written file report Test-Path, the line count and the exact test output (the Ran line, OK or FAILED, and the exit code).
6. If a write is rejected, report the exact error message and say NOT DONE. Never report done in that case.
7. Reviewers run the tests themselves and check that every file has CR=0 (no CRLF and no lone CR).
8. Write code, comments and file content in English. Write your answer in simple German.
